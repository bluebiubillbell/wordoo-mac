# Wordoo for Mac

A menu-bar quick look-up for [wordoo](https://wordoo.bingyu.uno), the
English–Chinese dictionary. Press **⌥W** anywhere: a small panel opens in the
top-right corner with the selected text already looked up, or on an empty
search box when nothing is selected. Escape, ⌘W or a click elsewhere closes it.

## Install

1. Download the latest **Wordoo-x.y.z.dmg** from
   [Releases](https://github.com/bluebiubillbell/wordoo-mac/releases/latest),
   open it and drag Wordoo to Applications.
2. Open Wordoo. If macOS says it cannot check the app for malicious software,
   go to **System Settings → Privacy & Security** and choose **Open Anyway**.
3. Allow Wordoo under **Accessibility** when asked, so it can read the
   selected text.
4. Sign in to your wordoo account in the panel once.

The shortcut can be changed from the menu-bar icon, which also has
**Open at Login**. Requires macOS 13 or later, on Apple silicon or Intel.

This repository holds only the releases.
